# `data` 目录

运行时数据目录。仓库只上传可公开的模板和本说明。

## 已上传文件

| 文件 | 作用 |
| --- | --- |
| `template_character.json` | 角色设定记录模板。 |
| `template_instruction.jsonl` | 指令微调数据格式示例。 |
| `template_notes.md` | 原始笔记和风格素材模板。 |
| `阮梅角色故事.md` | 阮梅四段亲历故事，供按问题检索并注入角色记忆。 |
| `README.md` | 本目录的用途与运行时文件说明。 |

## 本地运行时文件（不上传）

| 文件 | 作用 |
| --- | --- |
| `习惯.md` | 用户长期偏好，按小节注入提示词。 |
| `提醒.json` | 当前提醒列表。 |
| `提醒记录.json` | 提醒触发记录。 |
| `听歌记录.json` | 播放历史和音乐偏好统计。 |
