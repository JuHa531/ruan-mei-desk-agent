# `app/assets` 目录

界面背景、图标、表情包和素材元数据。仓库不包含大型 `.mp4` 背景视频。

## 图标与默认背景

| 文件 | 作用 |
| --- | --- |
| `bg.jpg` | 默认静态背景。 |
| `icon.png` | 应用主图标。 |
| `icon-192.png` | 192 像素网页/PWA 图标。 |
| `icon.ico` | Windows 多尺寸图标。 |
| `window.ico` | 桌面窗口图标。 |
| `说明.txt` | 素材来源与使用说明。 |
