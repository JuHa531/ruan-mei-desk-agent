这是「阮·梅」界面的素材库：背景图 / 背景视频 / 图标都放这里。

现在实际在用的（2026-10-10 设置）
---------------------------------
  bg.jpg        背景图
  icon.png      图标（512，界面侧栏头像 + 浏览器标签页图标都用它）
  icon-192.png  图标小尺寸（浏览器「安装成应用」时用）
  icon.ico      图标（桌面快捷方式「阮·梅」用的多尺寸 ico）

想换成别的图，不用手动转换格式，跑一条命令就行（会自动裁方形、生成 png/ico）：

    D:\ai\envs\llm\python.exe scripts\set_branding.py ^
        --icon "F:\你的图片\某图标.jpeg" ^
        --bg   "F:\你的图片\某背景.jpeg" --dim 70

    --dim 0~100 控制背景明暗：数字越小背景越清楚，越大文字越清楚。
    只换图标：只写 --icon 那一段。

两种换法，任选其一
------------------
1) 改名法（最省事，放进来就生效，重启界面即可）
     背景 -> 文件名改成 bg.jpg / bg.png / bg.mp4 / bg.webm
     图标 -> 文件名改成 icon.png / icon.ico / icon.svg

2) 界面里点（不用重启）
     右上角「🎨 外观」-> 下拉框选素材 -> 立刻生效
     也可以在那个面板里粘贴别的路径（如 D:\图片\a.png）直接导入

配置记在 app\appearance.json，删掉它就会退回「按文件名自动识别」。

建议规格
--------
  背景图    1920x1080 以上，颜色偏暗更好（界面文字是浅色）
  背景视频  mp4，10~30 秒循环，20MB 以内最顺
  图标      512x512 PNG，正方形，透明底更好看

支持的格式
----------
  图片  .jpg / .jpeg / .png / .webp / .gif / .bmp
  视频  .mp4 / .webm / .m4v / .mov   （自动静音循环播放）
  图标  .png / .ico / .svg
