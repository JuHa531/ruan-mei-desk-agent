## 操作

左键拖动，按住右键滚轮缩放；托盘菜单回到梅梅当前对话、打开桌宠设置或收起桌宠。设置内查看 Space 组合键和可选 Ctrl + Alt 组合键。若开启点击穿透，可按 Ctrl + Alt + P 恢复。

对话、麦克风、图片、音乐工具、会话历史和回复朗读直接使用梅梅现有界面，不另外创建一套聊天记录。桌宠偏好保存在 `app/desktop-profile/pet`；启用状态和大小在 `app/desktop-profile/pet-mode.json`。

打开桌宠设置时自动恢复并置顶、激活；设置关闭后结束该置顶窗口。从桌宠返回梅梅对话时恢复并激活主窗口，同时保留原有最大化状态。主窗口只在此次激活时临时提层，不持续抢占其他应用的焦点。

## 验证和边界

单元检查覆盖窗口、几何命中、动作状态、语音调度、桥接和取消流程。原生窗口检查覆盖移动缩放、透明形状、设置持久化、点击穿透恢复与渲染隔离。打包程序的实际联通检查完成：梅梅聊天、只读 QQ 音乐状态查询、录音识别、回复合成以及播放结束确认。

麦克风自动检查使用已知录音验证 ASR 通道，尚未用实体麦克风实际录制。全局热键有监听器和恢复入口，但未向其他应用注入快捷键验证。音质最终仍需实际试听，54 条生成语音未全部逐条人工验收。

人物为二维插画与骨骼蒙皮动画，动作精细度不等同于专门制作的 Live2D 模型。猫耳、眼镜等附件可关闭。内置组件由梅梅通过私有命名管道控制，Windows Job Object 负责主程序退出时清理整个渲染进程树，不增加远程控制接口。

当前单元检查 368 项通过，覆盖连续肘部蒙皮、定长三维关节、25 度腕部限制、抬手／放下、拿取进食、道具遮挡、真实计时、轨迹延迟和窗口恢复。真实 GPU 检查覆盖 12 种动作改选的首帧连续性和 84 个身体／手臂／道具窗口覆盖样本。`meimei-shoulder-check.cjs` 另检查原身体肩部清除、肘部无透明裂缝、实际盘沿覆盖手掌；近景为 `meimei-joints-review.png`，连续预览为 `desktop-pet/artifacts/meimei-actions.mp4`。4 项 Python 检查窗口激活和异常后的线程解绑；原生窗口与打包组件另行验证。

动画设置提供「头颈跟随」开关。眼周底色从邻近原画皮肤采样，保留原有渐变；虹膜补齐上眼睑后的隐藏部分，刘海作为前景遮挡眼睛。四动作近景回归脚本为 `node scripts/meimei-face-check.cjs`，产物在 `desktop-pet/artifacts/meimei-face-check.png`。

骨盆、脊柱、胸部、颈部、头部构成主骨骼链，四肢、发束、衣袖和飘带继承对应父骨骼。局部变换仅使用旋转并保持骨骼长度，每个顶点最多使用四项归一化权重；已移除用上半身缩放和整体位移模拟转头的旧方法。设置中的「骨骼预览」默认关闭，打开后显示关节与连接线。`node scripts/meimei-skeleton-check.cjs` 用实际 GPU 渲染验证肩胸固定、头部刚性旋转并记录对照视频；眼镜、运动模糊与点击检测共用骨骼变换。

指针在下方时，颈部骨骼弯曲、头部反向补偿形成小幅下沉；虹膜纵向跟随幅度为 6 原画像素，最高设置时为 12 像素，隐藏虹膜仍覆盖该范围。对白气泡采用深青蓝底、浅青边框和浅色文字，尾角与气泡同色；预览为 `desktop-pet/artifacts/meimei-speech-theme.png`。

动作使用同一净身图、连续手臂、手掌与道具。餐盘从侧面拿入，餐叉先到点心上方、向下切入、抬起小口并转向嘴边，吃下后先撤叉再放低；杯子在柄侧指尖到位后出现，单手举起抿饮，自由手不跟随杯子托底。日常双手在腹前放松交叠，保留轻微身体平衡和腕部微摆。三维关节长度固定，肘部以向下且略向外的方向弯曲，手腕最多 25 度；不缩放上半身，不切换完整人物图。头脸和青蓝挑染仍用原立绘。

动画设置中的「拿取与收回动作」可单独开关，「拿取与进食速度」范围为 0.6～1.6 倍；「骨骼与日常待机动作」控制轻摆和周期进食／抿茶，运动模糊保留独立强度。切换包含约 0.9 秒收回和 0.9～2 秒拿取，实际时长由动作决定；旧 0.46 秒整图交接已移除。快速选择从当前手部位置接续，不排队。窗口范围按当前与短期预测的透明轮廓更新，避免餐盘或手臂移出原身体轮廓后被裁切。

手臂新素材 `ruanmei-continuous-arms-v3.png` 从肩到腕为一整条，`arm-skin.mjs` 用连续网格连接肩／肘／腕，深弯曲时保持肘部宽度。旧身体的固定肩膀已清除，活动肩根从锁骨后接入，前臂再覆盖身体；不再叠加两套圆肩，也不再拼接带封口的上臂／前臂。手腕在珠串下衔接。承托掌先画，餐盘／杯子随后遮挡，握杯和捏叉只有前端手指重新放到道具前层。逆向拾取、运动模糊和原生窗口范围使用同一蒙皮公式。

闭眼参考保存在 `desktop-pet/assets/reference/ruanmei-closed-eye-reference.jpg`，仅用于本地维护，不打入组件。`closed-eyes.mjs` 直接绘制睫毛轮廓，与原画眉形联动，不使用另一张脸部图片。发梢挑染保持素材原有的青蓝色，未启用深蓝替换；四动作检查同时核对挑染和服饰像素。

首次使用需要梅梅服务预热，英文新句首次生成较慢；重复语句使用现有缓存。QQ 音乐点播等工具仍依赖对应应用、登录和曲目权限。本机接口保持原有访问限制，没有额外暴露远程接口。
