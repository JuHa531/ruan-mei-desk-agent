# 桌宠动作延迟与窗口修复

2026-10-30。以下是本机检查结果，帧率会随窗口大小、显示器和其他程序负载变化。

## 原因

本轮采样中，RTX 4060 Laptop 显存为 2422/8188 MiB，没有接近容量上限。浏览器渲染检查实际使用 Intel UHD 的 ANGLE / Direct3D 11。显存容量不是此次慢动作的主要原因，不能据此判断语音模型加载时的占用。

原实现每帧在 1090×1443 的离屏画布渲染整个人物，持续进行三次运动模糊采样，多次在 WebGL 与 Canvas 之间合成；即使桌宠很小，也承担完整像素开销。相同本机检查中，开启模糊时只有约 12～14 fps。计时还把每帧最多按 40 ms 处理，低帧率时实际一秒仅推进约 0.49～0.54 秒，产生真实慢放。

鼠标轨迹绘制本身平均约 0.15～0.23 ms；但旧协议没有计入主进程到渲染器之间的排队时间，繁忙时旧位置到达后仍被当成新轨迹，延长了拖尾的实际寿命。

## 修改

1. 离屏画布和 GPU 绘制分辨率跟随实际显示像素，并保留约 1.5 倍超采样；上限为原图尺寸，缩小时减少无效像素与跨画布复制，放大时保留原图清晰度。
2. 根据真实手臂／道具位移及可见像素选择曝光采样。极小待机摆动无需重复绘制三个人物；可见的抬手、取食、抿茶、眨眼和跟随保留短曝光模糊，慢帧采用两次采样控制开销。没有把运动模糊总开关关掉。
3. 动作、眨眼、身体和头部缓动按真实帧间隔推进；仅休眠／长暂停限制为 250 ms。弹簧单独以最多 20 ms 的小步积分，避免为了稳定弹簧而拖慢所有动作。
4. 轨迹协议携带发送时间，接收时扣除 IPC 排队耗时，过期位置直接丢弃。
5. 内置组件启动后记录一次实际窗口的帧率、计时比及图形加速状态，位于 `logs/pet-renderer.log` 的 `performance` 事件；不新增网络调试端口。

## 验证

`desktop-pet/scripts/meimei-performance-check.cjs --label=after` 使用实际生产渲染器、三维 IK、运动模糊和窗口边界计算。294×392 画布、同机 Intel 核显的对照结果：

| 场景 | 开启模糊后的 fps | 动画计时／实际时间 |
| --- | ---: | ---: |
| 原实现待机／持物 | 12～14 | 0.49～0.54 |
| 优化后待机／持物 | 107～113 | 1.00 |
| 优化后送点心入口 | 70.5 | 1.00 |
| 优化后举杯抿茶 | 94.3 | 1.00 |
| 优化后抬手切换 | 65.6 | 1.00 |
| 优化后持续视线跟随 | 77.1 | 1.00 |

这是自动渲染对照，不代表桌面窗口保证达到这些数字；桌面实际帧率另受刷新率及窗口合成限制。原始数据为 `desktop-pet/artifacts/meimei-performance-before.json` 与 `meimei-performance-after.json`。

部署后，梅梅实际管理的桌宠窗口在原有 49% 大小、运动模糊开启的状态下，启动采样约 87.5 fps，计时比 1.00；实际窗口同样使用 Intel UHD / Direct3D 11，GPU 合成、光栅化与 WebGL 均启用。已打包并重启梅梅，实测设置打开／最小化恢复后置顶且获得焦点、返回主窗口、正常退出及异常退出清理通过。此采样不是持续的最低帧率保证。

368 项单元检查覆盖 10／15／24／60／144 fps 下四秒的真实计时、弹簧稳定性、轨迹过期、连续关节与遮挡等；实际 GPU 检查保持 12 种切换首帧连续和 84 个窗口范围样本通过。关节近景检查包含肩部唯一所有权、无透明肘缝及盘沿遮挡承托掌。

## 肩部、手腕与窗口

原身体保留肩帽、活动臂又画了一套肩帽，是重叠肩膀的来源。新 `ruanmei-continuous-arms-v3.png` 从肩到腕为连续图，`arm-skin.mjs` 用一张连续网格蒙皮，肘部保留宽度；旧身体肩帽移除，肩根从锁骨后方衔接，前臂在身体前方。手腕在珠串下衔接。承托掌在餐盘后，握杯／捏叉只将前端手指放到道具前。

设置打开时恢复、置顶并激活；渲染器通知梅梅后，由父进程按窗口标题和子进程 PID 核验并激活，解决 Windows 在再次打开最小化窗口时不授予焦点的问题。返回梅梅时保留最大化状态，临时提高层级后恢复普通窗口层级；不靠模拟按键抢焦点。

原声音配置、中文 D1 节奏、英文 D1/U1、人设和青蓝挑染保持原样。新手臂由内置 image_gen 生成，素材和最终提示词见 `desktop-pet/assets/character/ruanmei-puppet-generation.md`。
