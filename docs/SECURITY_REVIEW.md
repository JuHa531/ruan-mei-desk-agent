# 安全边界

梅梅默认作为本机桌面助手运行，HTTP 控制接口不面向未鉴权的远程访问。

- 本地服务校验客户端、Host、Origin 和跨站请求，限制请求大小及不明确的请求长度。
- GPT-SoVITS 通过本机请求保护包装器启动，上游推理实现保持独立。
- 文件路径按真实路径解析，限制符号链接、目录联接及搜索越界，搜索规模有上限。
- 任意脚本、复合命令、危险快捷键和手机 shell 需要明确授权；否定句不能当成同意。
- 对话接口校验历史角色和内容类型，拒绝伪造 system/tool 历史。
- WebView 只为精确的本机应用来源自动允许麦克风。
- 高影响工具仍按当前 Windows 用户权限运行，确认流程不等同于操作系统级沙箱。

应用、语音和训练环境分开维护。语音环境可能因 Python、PyTorch、Gradio、Transformers 的兼容要求
保留旧版本，应独立扫描和验证，不应直接开放其 Web UI 或控制 API。
远程控制应经过鉴权网关，并限制能够访问本机功能的设备与用户。

检查工具：`scripts/doctor.py`、`scripts/test_security.py`、`scripts/test_agent_regressions.py`。
信号检查和转写检查不能替代语音的主观试听；测试通过也不表示不存在其他漏洞。
