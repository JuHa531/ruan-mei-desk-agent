# 功能范围

| 能力 | 实现 | 使用前提与范围 |
| --- | --- | --- |
| 日常对话 | Ollama、本地角色模型、会话与相关记忆 | 模型需要自行准备；复杂任务仍可能误解 |
| 语音对话 | GPT-SoVITS、SenseVoiceSmall、播放队列 | 需要独立语音环境与音色参考 |
| 图片理解 | 中文 OCR、本地视觉模型 | 支持上传、粘贴、拖放；CPU 视觉较慢 |
| 音乐 | QQ 音乐点播、SMTC 控制、听歌记录 | 依赖安装、登录和曲目权限；记录播放事件，不代表完整听完率 |
| 习惯与提醒 | 本地习惯、偏好、提醒记录 | 由对话和工具调用记录，不持续监视个人生活 |
| 日常规划 | 提醒、日程和学习计划表 | 可生成 Excel 规划，不等同于已连接云日历 |
| 文件与电脑 | 工作目录文件操作、系统检查、应用启动/切换 | 不是操作系统级沙箱，也不是任意控件点击代理 |
| 办公文件 | Word、Excel、PowerPoint | 使用本地 Python 文档库生成 |
| 视频 | FFmpeg 剪切、拼接、变速、音轨、缩放、动图 | 基础媒体处理，不含语义自动剪辑或剪映工程编辑 |
| 安卓设备 | ADB、设备 serial 选择 | 设备连接并允许调试后才能操作 |
| 设备网络 | 可结合 Tailscale 配置 | 不自动完成配对；远程控制需鉴权网关 |
| 桌面与表情 | 自适应三栏、背景图库、表情库 | 自动表情按回复内容匹配，可关闭 |

运行 `python scripts/doctor.py` 查看本机组件状态，`/api/status` 查看对话和语音服务是否在线。
