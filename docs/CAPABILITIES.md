# 功能范围

设置支持请求批准／帮我批准／完全批准，工具默认不限轮数，可在需求中指定上限；执行详情默认收起。主界面和桌宠聊天各自支持单条朗读互斥，主界面重播仅复用完整缓存。详见 [权限与朗读说明](PERMISSIONS_AND_SPEECH.md)。

| 能力 | 实现 | 使用前提与范围 |
| --- | --- | --- |
| 日常对话 | 本地 Ollama 或 GPT／DeepSeek／Claude／兼容 API，共用人设、会话与相关记忆 | 顶栏「设置 → 模型与 API」配置地址、模型 ID 和密钥；云端真实账号待用户测试，参见 [配置说明](MODEL_API.md) |
| 语音对话 | GPT-SoVITS、SenseVoiceSmall、播放队列、中英混合与缩写读法 | 需要独立语音环境与音色参考；英文口音与韵律仍受参考和训练素材影响 |
| 图片理解 | 中文 OCR、本地视觉模型 | 支持上传、粘贴、拖放；CPU 视觉较慢 |
| 音乐 | QQ 音乐点播、SMTC 控制、听歌记录 | 依赖安装、登录和曲目权限；记录播放事件，不代表完整听完率 |
| 习惯与提醒 | 本地习惯、偏好、提醒记录 | 由对话和工具调用记录，不持续监视个人生活 |
| 日常规划 | 提醒、日程和学习计划表 | 可生成 Excel 规划，不等同于已连接云日历 |
| 文件与电脑 | 工作目录文件操作、系统检查、应用启动/切换 | 不是操作系统级沙箱，也不是任意控件点击代理 |
| 办公文件 | Word、Excel、PowerPoint | 使用本地 Python 文档库生成 |
| 视频 | FFmpeg 剪切、拼接、变速、音轨、缩放、动图 | 基础媒体处理，不含语义自动剪辑或剪映工程编辑 |
| 安卓设备 | ADB、设备 serial 选择 | 设备连接并允许调试后才能操作 |
| 设备网络 | 可结合 Tailscale 配置 | 不自动完成配对；远程控制需鉴权网关 |
| 桌面与表情 | 自适应三栏、背景图库、表情库 | 自动表情按回复内容匹配，可关闭 |
| 内置阮梅桌宠 | 梅梅统一启停、骨骼蒙皮与定长手臂 IK、头颈与双眼跟随、拿点心／变杯／进食／抿茶／收回动作、自然待机和短曝光模糊、参考闭眼眉眼、拖动缩放、问候互动 | 顶栏「桌宠」调整大小；动画设置调整动作速度或关闭日常循环；沿用主界面对话与语音；3 种动作（待机／点心／双手端杯）、青蓝主题按键显示、36 条问候与 18 条互动语音。详见 DESKTOP_PET.md |

运行 `python scripts/doctor.py` 查看本机组件状态，`/api/status` 查看对话和语音服务是否在线。

桌宠设置打开时自动恢复、置顶并获得焦点；从桌宠返回对话时自动激活梅梅主窗口。手臂采用连续肩肘腕蒙皮，承托手掌位于托盘下层，握杯和捏叉只将指尖置于道具前层。
