# 对话模型 API 配置

在梅梅顶栏点击 **设置 → 模型与 API**，选择本地 Ollama、GPT / OpenAI、DeepSeek、Claude / Anthropic 或自定义 OpenAI 兼容服务。

1. 官方服务自动填入 API 基础地址。自定义服务填写 HTTPS 基础地址，不要附加 `/chat/completions` 或 `/messages`。
2. 填写平台提供的准确模型 ID 和对应 API 密钥；模型需支持所用协议，执行任务还需支持工具调用。
3. 点击 **测试连接**。只发送一条简短测试文本，不发送聊天、记忆或工具结果；可能产生少量 API 费用。测试不保存配置、不切换当前模型。
4. 点击 **保存并启用**，下一轮对话生效，不用重启。进行中的一轮保持原来的服务与凭据。

各服务单独保存配置。已保存密钥不回显，留空保留，填写新值替换。勾选清除密钥并保存，会清除该服务密钥并切回本地。更换服务地址必须重新输入密钥，避免将原密钥传给新站点。选本地并保存即可恢复本地推理；本地模型 ID 留空沿用启动参数。

## 人设、声音与工具

- 云端模型沿用现有阮梅人设、相关角色资料、相关习惯和当前对话；不上传或加载本地 LoRA 权重，不承诺输出与本地训练模型完全一致。
- 原有本地语音识别、GPT-SoVITS、中文语速／停顿、英文 D1／U1、表情和桌宠继续沿用。未加入二次本地模型润色。
- 工具仍在本机执行，并沿用权限检查；API 适配保留工具调用 ID、多轮结果和 DeepSeek 推理字段，Claude 使用原生 Messages 格式。
- 图片仍由原有本地视觉／OCR 工具处理，不直接上传原图给云端；识别结果可能作为工具结果发送。
- 启用云端后，会向所填地址发送必要的对话、人设、相关记忆及工具结果。原始录音仍在本地识别，转写文本会作为对话发送。
- 云端故障会明确报错，不自动重复执行工具或悄悄切换服务。状态栏“已配置”不代表已验证网络、余额和权限；使用测试连接验证文本访问，工具能力需通过实际任务验证。

## 存储与验证

`app/model-api.local.json` 保存非敏感配置和 Windows DPAPI 加密的密钥，仅当前 Windows 账户可解密；文件已被 Git 忽略。密钥不写浏览器持久存储，不从读取配置接口返回，不输出服务商原始错误响应；拒绝 HTTP 重定向以避免凭据转发。备份迁移到新账户后应重新填写密钥。

使用 Python 标准库，无需安装新插件。相关检查：`scripts/test_model_api.py`（临时配置、DPAPI、凭据生命周期、三类协议工具往返、HTTP 设置与主 Agent 工具循环），原有 `scripts/test_agent_regressions.py`、`scripts/test_bilingual_role.py` 与 `scripts/test_speech_queue.mjs`。

2026-11-02：协议与界面使用模拟服务测试，没有真实云端 API 密钥，未验证真实账户额度、模型访问权限或云端角色听感。当前默认仍是本地模型。

协议参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)、[Claude Tool Use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

## 统一设置与会话

顶栏只保留「设置」。设置面板集中提供模型与 API、自动朗读、朗读方式、桌宠、外观与偏好、右侧栏开关。语音生成提示仍使用单独状态行，窄窗口也不把设置按钮挤到新行。

每次启动或重新加载 APP 页面都显示新对话，不自动恢复旧会话。已有内容可从历史手动打开；仅最小化／恢复窗口不会重置当前对话。空白会话不写入历史，过去产生的空白占位会在加载时过滤。仅呼叫唤醒词及自动应答作为临时内容，后续真的交流才随会话保存；正常发送的文字、图片和主动表情操作保留，失败请求的用户内容也不会因没有成功回复而删除。草稿文字未发送不计入历史。

浏览器生命周期检查：`node scripts/test_session_lifecycle.cjs`，使用独立临时 Edge 浏览器上下文和模拟对话接口，不读写桌面 APP 的历史存储。

## 输入区快速切换

输入框上方新增模型按钮，显示当前供应商／型号。可切换已配置服务、填写新型号或选择最近型号（每服务最多12个）；密钥复用且不回显。未配置服务提供前往设置的入口。下一轮生效，当前轮使用原配置，对话保留。8项API回归、浏览器宽窄屏与切换流程、密钥保留／型号历史检查通过。测试使用模拟服务，不代表全部云端型号可用。
